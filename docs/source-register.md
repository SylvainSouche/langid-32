# Source register — canonical status

**Last reconciled: 18 November 2026.** This is the canonical index of every dataset/source family actually acquired, staged, sampled, investigated, rejected, or retired for langid-32. It supersedes the source-discovery and acquisition-priority narrative in older inventory documents. Historical audit reports remain available but are not current source-status statements.

Status vocabulary:
- **STAGED** — an acquisition or sample artifact exists; this does not mean the source is legally cleared.
- **PILOT** — limited technical sample; not part of a release-ready corpus.
- **INVESTIGATED** — documentation/catalogue examined, but no usable text has been acquired into the current candidate pipeline.
- **HOLD** — technically acquired or sampled, but rights/terms or required attribution remain unresolved.
- **NOT PURSUED / RETIRED** — route was considered but is not part of the current acquisition plan.
- **FAILED** — attempted acquisition did not yield usable source data.

No source in this register is automatically approved for public redistribution. The latest global candidate build is run [44316929956](https://github.com/SylvainSouche/langid-32/actions/runs/44316929956): it completed successfully and uploaded metadata only. Its manifest reports 654,401 core records and 135,851 reserve records across 34 labels; 26 labels reached the 20,000-record core target and eight did not. This is a technical candidate, not a rights-cleared corpus. The build's Common Voice rights-status fallback was corrected in commit [a703bda](https://github.com/SylvainSouche/langid-32/commit/a703bda2409cf2c1fa0b9a7443f47c4980073e39); a refreshed candidate manifest is pending.

## Voluntary source-selection decision

The project voluntarily does not use the Mozilla Data Collective (MDC) repository or any data hosted there. We consider its contractual practices abusive. This is a project sourcing decision, not a legal conclusion.

Croatian (`hr`) remains a target label, and no Common Voice source is retained for it. The latest candidate contains 14,988 Croatian core records from DGT-TM and FineWeb2, below the 20,000 minimum. A promising independent alternative has now been identified: MaCoCu-hr 2.0 (CC0-labelled, CLARIN.SI-hosted); it is investigated but not yet acquired or integrated.

**How to read the stars:** this is a qualitative estimate of the likelihood of finding enough *technically useful, independently sourced and potentially redistributable* material—not a measure of language availability on the web. A high rating does not mean the sources have been legally cleared.

**Source concentration rule:** the percentages above describe the actual current core composition, not the target quota. To meet a 30% maximum, a language generally needs at least four substantial independent sources; to meet 50%, at least two. Source independence matters: two repackagings of the same underlying web pages do not count as independent sources. Until FineWeb2's underlying page rights are resolved, the apparent capacity it supplies is provisional.

## 4. Current acquisition priorities

1. **Leipzig Corpora Collection — first priority: complete the technical and rights audit, fix the acquisition route, and integrate usable corpora.** Work across all 20 currently observed target labels, inspect the full catalogue rather than only the largest two corpora, establish reproducible bulk/API acquisition, retain sentence-to-source provenance (source ID, URL, date, corpus name and revision where available), and quantify usable yield, source concentration and language coverage. Resolve the API's CC BY 4.0 declaration and usage terms alongside the underlying corpus-family/source-work rights. Treat the 20-label REST catalogue as a starting coverage map, not a limit on the full Leipzig collection.
2. **Reconcile existing staged sources**: immutable revisions, per-file manifests, licence evidence, attribution and provenance. Do not let this block the Leipzig technical investigation.
3. **Diversify source mix** in Catalan, Icelandic, Bokmål, Nynorsk, Korean and Arabic. Current waiting-source samples are concentrated: TeMU is large in Catalan; IGC dominates non-FineWeb2 Icelandic; Målfrid is the only source in each Norwegian batch; Wikipedia is the only Korean source; UN-derived data is the only Arabic source.
4. **Resolve the non-Leipzig source holds**: BSC constituent terms, TeMU constituent waivers, Greynir test/dev-sample provenance, IGC source-document grant/metadata, Målfrid database/third-party terms, Korean Wikipedia share-alike and UN attribution packaging. Catalan-DPO-V2 is excluded from acquisition pending a Catalan-only, source-traceable sample.
5. Keep FineWeb/FineWeb2/HPLT out of a redistributable release unless a defensible excerpt-level rights process is established; their compilation licences are not passage licences.
6. Rebuild the global 34-label candidate after Leipzig integration and the common privacy, language, deduplication, group-split and source-quota checks.
