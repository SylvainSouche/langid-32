# European Commission DGT Translation Memory 2021

**Text unit:** Translation units / segment pairs  
**Primary source:** https://joint-research-centre.ec.europa.eu/language-technology-resources/dgt-translation-memory_en

## Creator and origin

Directorate-General for Translation, European Commission; Acquis Communautaire texts indexed by EUR-Lex.

## Access methods

Official JRC page; five ZIP volumes (Vol_2020_1…5, ~583 MB total) and Java extractor; all volumes needed for full parallel coverage.

## File types and structure

ZIP/TMX plus TXT language/document lists.

## Distribution conditions and rights

Commission owns database and grants worldwide, royalty-free, non-exclusive reuse subject to Decision 2011/833/EU. Preserve attribution and conditions.

## Content and language coverage

EU legislation; official JRC says 24 languages and provides per-language statistics PDF.
