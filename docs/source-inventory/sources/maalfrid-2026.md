# Målfrid 2026 — Norwegian state institutions

**Text unit:** Documents / text records  
**Primary source:** https://www.nb.no/sbfil/tekst/maalfrid_2026/maalfrid_2026.pdf

## Creator and origin

National Library of Norway, on behalf of Ministry of Culture with Language Council of Norway.

## Access methods

Official TAR archives; project downloads nob and nno archives via HTTPS; Data Norge catalogue; no API listed.

## File types and structure

TAR with document files; project scans JSONL/TXT/TSV/CSV.

## Distribution conditions and rights

Catalogue says open, but project holds pending database and third-party content review.

## Content and language coverage

720 Norwegian state-institution domains; focused crawl Dec 2025–Jan 2026; ~2.6B tokens: Bokmål 1.890B, Nynorsk 170.2M, English 570.1M, Northern Sami 2.4M, Southern Sami 415k, Lule Sami 329k.

## Provider-reported structure and package metadata

The National Library of Norway's resource catalogue specifies one JSONL record per document, with one JSONL file per domain/content-type combination; each record includes document ID/hash, domain, URL, crawl date, MIME type, detected language and paragraph-array full text. The crawl covers 720 state-institution domains and ran from December 2025 to January 2026. Official archive sizes listed in the catalogue are 3.8 GB for Bokmål (nob), 342.1 MB for Nynorsk (nno), 6.3 MB for Northern Sami (sme), 1,020 KB for Southern Sami (sma), and 770 KB for Lule Sami (smj); the catalogue also lists an English archive. The PDF reports language-specific token counts, but no per-language document counts. Therefore, archive sizes and token counts must not be converted into document or sentence counts. The catalogue declares the Norwegian Licence for Open Government Data (NLOD) 2.0; langid-32's project-level third-party review remains separate. Sources: https://www.nb.no/sprakbanken/ressurskatalog/oai-nb-no-sbr-107/ and https://www.nb.no/sbfil/tekst/maalfrid_2026/maalfrid_2026.pdf
