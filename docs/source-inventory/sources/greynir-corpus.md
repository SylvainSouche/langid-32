## Verified upstream availability

The CLARIN-IS repository record reports **10 million sentences** and **110,893,504 tokens**. The upstream project README independently describes 10 million parsed sentences and approximately 140 million words; the difference in token/word accounting should be retained as a metadata discrepancy, not silently reconciled. The corpus contains 5,000 hand-annotated parse trees as a gold-standard subset, not an additional 5,000 sentences. Publicly available under **CC BY 4.0** according to CLARIN-IS.
